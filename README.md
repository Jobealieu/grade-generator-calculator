# Grade Generator Calculator

## Project Overview
A Python application that assists students in understanding how their assignment grades contribute to their overall course grade. The application calculates weighted grades, computes GPA, and determines pass/fail status.

## Features
- Input collection for assignments (name, category, weight, grade)
- Assignment categorization (Formative/Summative)
- Weighted grade calculations
- GPA calculation (out of 5.0)
- Category-wise grade totals
- Pass/fail determination based on category averages
- Input validation and error handling

## Usage
1. Run the main program: `python a.jobe@alustudent.com_IL-1.py`
2. Choose options to add assignments or view results
3. Use option 3 to load test transcript data

## Programming Concepts Used
- Object-Oriented Programming (Classes and Objects)
- Data Validation and Error Handling
- Lists and Dictionaries for data storage
- Loops for repetitive operations
- Conditional logic for decision making
- File structure organization
- User input/output operations
- Mathematical calculations and formulas
